# Currency sample photographs

The six sample banknote photographs in this folder are from the Roboflow Philippine Banknotes v8 dataset. The dataset identifies its license as Creative Commons Attribution 4.0 International (CC BY 4.0).

Attribution: “Philippine Banknotes v8” by the Roboflow Philippine Banknotes project, [Roboflow Universe](https://universe.roboflow.com/philippine-banknotes/philippine-banknotes/dataset/8), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Images are used as denomination examples and cropped by the interface for display.

These are sample photographs, not official reference images or authenticity examples. Banknote series and features vary.
