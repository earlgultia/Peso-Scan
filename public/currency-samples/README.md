# Currency sample photographs

`php-{50,100,500,1000}-polymer-{front,back}.jpg` are user-provided, visibly watermarked SPECIMEN reference images. The demo labels them as specimens and shows front/back views. They are interface examples only and are not included in the AI training dataset.

The Currency Library shows these photos only on matching polymer entries. Paper note entries show a no-photo placeholder because no matching paper specimens were supplied. Sample images are for learning only and do not establish banknote authenticity.
